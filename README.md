# Bushidō AR

Web AR for the armour photo. Open https://superpranit.github.io/bushido-ar/ on a phone: the camera starts by itself (allow it when asked); point it at the armour photo (`armour-target.jpg`, or the poster in `poster-A3.pdf`). Runs in the browser on iPhone and Android, with no app to install.

- `index.html`: the whole experience in one file (MindAR image tracking + three.js; the tracking target and artwork are embedded).
- `armour-target.jpg`: the image the camera tracks. Print or display it unaltered.
- `poster-A3.pdf`: print-ready A3 poster with the QR code.
